# MCP 기반 QA 자동화 기술 백서: LLM과 Manus를 활용한 혁신

## 1. 서론: 기존 QA의 한계와 AI 시대의 도래

전통적인 QA 프로세스는 수동 테스트의 반복성, 자동화 코드 유지보수의 어려움, 그리고 급변하는 서비스 환경에 대한 느린 대응 속도라는 본질적인 한계를 가지고 있습니다. 특히 LLM(Large Language Model) 기반의 AI 서비스가 확산되면서, 기존의 정형화된 테스트 방식으로는 예측 불가능한 AI의 동작을 검증하기 어려워졌습니다. 본 백서는 이러한 문제 인식을 바탕으로, LLM과 MCP(Model Context Protocol)를 활용하여 QA 프로세스를 혁신하고, 엔지니어의 생산성을 극대화하는 새로운 접근 방식을 제안합니다.

## 2. MCP(Model Context Protocol)의 이해

MCP는 AI 모델이 외부 도구(Tool)와 상호작용할 수 있도록 표준화된 인터페이스를 제공하는 프로토콜입니다. AI는 MCP를 통해 파일 시스템 접근, GitHub 저장소 관리, 웹 브라우저 제어, 메시징 서비스 연동 등 다양한 외부 시스템을 마치 자신의 손발처럼 활용할 수 있게 됩니다. 이는 AI가 단순한 정보 생성 도구를 넘어, 실제 업무 환경에서 능동적인 에이전트 역할을 수행할 수 있도록 하는 핵심 기술입니다.

## 3. LLM 기반 QA 자동화 파이프라인 설계

본 포트폴리오에서 제시하는 LLM 기반 QA 자동화 파이프라인은 다음과 같은 '기승전결'의 흐름을 가집니다.

### 3.1. [기] 문제 제기: 수동 QA 및 기존 자동화의 병목 현상

*   **수동 테스트의 비효율성:** 반복적인 수동 테스트는 시간과 인력 소모가 크며, 휴먼 에러 발생 가능성이 높습니다.
*   **자동화 코드 유지보수:** 테스트 시나리오 변경 시 자동화 코드의 잦은 수정이 필요하며, 이는 또 다른 병목 현상을 야기합니다.
*   **AI 서비스 검증의 난이도:** LLM 기반 서비스는 예측 불가능한 응답을 생성할 수 있어, 기존의 정형화된 테스트 방식으로는 커버하기 어렵습니다.

### 3.2. [승] 기술적 해법: LLM과 MCP의 결합

LLM은 자연어 이해 및 생성 능력을 통해 복잡한 요구사항을 분석하고 테스트 시나리오를 생성하는 데 탁월합니다. 여기에 MCP를 결합함으로써, LLM은 단순 아이디어 제공을 넘어 실제 QA 도구들을 직접 제어하고 워크플로우를 자동화할 수 있게 됩니다.

*   **LLM의 역할:** 기능 명세 분석, 테스트 케이스(TC) 생성, 결함 리포트 초안 작성, 테스트 전략 수립 지원.
*   **MCP의 역할:** LLM이 생성한 결과물을 실제 시스템(파일 시스템, GitHub, Playwright 등)에 적용하고 실행하는 인터페이스 제공.

### 3.3. [전] 실제 구현: 5가지 MCP 서버를 활용한 오케스트레이션

본 포트폴리오에서는 5가지 핵심 MCP 서버를 유기적으로 연동하여 QA 자동화 파이프라인을 구축했습니다.

1.  **Filesystem MCP:** 테스트 케이스, 결함 리포트, 전략 문서 등 다양한 QA 아티팩트를 파일 형태로 생성 및 관리합니다.
    *   **활용 예시:** LLM이 생성한 테스트 케이스를 `testcase_*.md` 파일로 저장.
2.  **GitHub MCP:** 소스 코드 버전 관리, 테스트 코드 커밋 및 푸시, GitHub Pages를 통한 포트폴리오 웹사이트 배포를 자동화합니다.
    *   **활용 예시:** Playwright 테스트 코드 커밋, 포트폴리오 웹사이트 업데이트.
3.  **Playwright MCP:** 웹 애플리케이션의 E2E(End-to-End) 테스트를 자동화하고, 실제 사용자 시나리오를 검증합니다.
    *   **활용 예시:** 포트폴리오 웹사이트의 주요 기능(링크 클릭, 텍스트 확인 등) 자동 검증.
4.  **Notion MCP (확장 가능):** 테스트 계획, 결과, 결함 추적 등 QA 관련 정보를 Notion 데이터베이스에 연동하여 관리합니다.
    *   **활용 예시:** LLM이 생성한 TC를 Notion DB에 자동 등록, 테스트 결과 자동 업데이트.
5.  **Slack MCP (확장 가능):** 테스트 결과, 중요 결함 발생 시 팀원들에게 실시간으로 알림을 전송하여 빠른 대응을 가능하게 합니다.
    *   **활용 예시:** CI/CD 파이프라인과 연동하여 테스트 실패 시 Slack 채널에 메시지 전송.

이러한 MCP 서버들의 유기적인 연동을 통해, LLM은 QA 프로세스의 전반에 걸쳐 능동적으로 개입하고, 엔지니어는 고부가가치 업무에 집중할 수 있게 됩니다.

### 3.4. [결] 가치 증명 및 미래 비전: AI 기반 자율 QA로의 전환

LLM과 MCP를 활용한 QA 자동화는 다음과 같은 가치를 제공합니다.

*   **생산성 극대화:** 반복적인 업무를 AI가 처리함으로써 QA 엔지니어의 업무 효율을 획기적으로 향상시킵니다.
*   **품질 향상:** AI의 광범위한 시나리오 생성 능력과 자동화된 실행을 통해 결함 발견율을 높이고, 서비스 품질을 안정화합니다.
*   **빠른 시장 대응:** 새로운 기능 출시 시 테스트 주기를 단축하여 시장 변화에 민첩하게 대응할 수 있습니다.

궁극적으로 본 접근 방식은 QA 엔지니어가 단순 테스터를 넘어, AI를 활용하여 품질 시스템을 설계하고 혁신하는 **'AI QA 아키텍트'**로 진화하는 미래 비전을 제시합니다. 이는 벙커키즈와 같은 AI 기반 서비스 기업에서 필수적인 역량으로 자리매김할 것입니다.

## 4. 결론

LLM과 MCP의 결합은 QA 프로세스에 새로운 패러다임을 제시합니다. 본 포트폴리오는 성기현 QA 엔지니어가 이러한 최신 기술을 이해하고, 실제 업무에 적용하여 혁신적인 가치를 창출할 수 있음을 증명합니다. 이는 단순한 이력서가 아닌, AI 시대의 QA 엔지니어로서의 비전과 실행력을 보여주는 강력한 증거가 될 것입니다.
