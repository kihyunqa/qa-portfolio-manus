# 샘플 테스트 케이스: AI 챗봇 답변 정확성 검증

## 1. 테스트 정보
*   **테스트 ID:** TC-AI-CHAT-001
*   **테스트 목표:** AI 챗봇이 사용자 질문에 대해 정확하고 적절한 답변을 제공하는지 검증
*   **테스트 유형:** 기능 테스트, 정합성 테스트
*   **우선순위:** High
*   **테스트 환경:** Web (Chrome), Mobile (Android/iOS App)

## 2. 사전 조건
*   AI 챗봇 서비스가 정상적으로 구동 중이어야 함.
*   테스트 계정으로 로그인되어 있어야 함.

## 3. 테스트 절차
| 단계 | 절차 | 기대 결과 |
| :--- | :--- | :--- |
| 1 | 챗봇 대화창에 "오늘 날씨 어때?"라고 입력 후 전송 | 1. 현재 위치 기반의 정확한 날씨 정보(온도, 강수 확률 등)를 제공한다.<br>2. 날씨 관련 추가 질문(예: "내일은?", "미세먼지는?")에 대한 가이드를 제공한다. |
| 2 | 챗봇 대화창에 "벙커키즈 서비스는 뭐야?"라고 입력 후 전송 | 1. 벙커키즈 서비스에 대한 정확한 설명(주요 기능, 특징 등)을 제공한다.<br>2. 서비스 관련 추가 정보(예: "요금제는?", "사용법은?")에 대한 가이드를 제공한다. |
| 3 | 챗봇 대화창에 "점심 메뉴 추천해 줘"라고 입력 후 전송 | 1. 일반적인 점심 메뉴를 3가지 이상 추천한다.<br>2. 사용자 위치나 선호도를 묻는 추가 질문을 통해 맞춤형 추천을 시도한다. |
| 4 | 챗봇 대화창에 "나는 오늘 기분이 너무 안 좋아"라고 입력 후 전송 | 1. 사용자의 감정을 인지하고 공감하는 답변을 제공한다.<br>2. 기분 전환에 도움이 될 만한 제안(예: 음악 추천, 가벼운 대화)을 한다. |
